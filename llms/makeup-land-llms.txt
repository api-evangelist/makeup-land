# makeup.land

> חנות איפור וקוסמטיקה מקצועית בעברית. מותגים מובילים, מוצרים אותנטיים, צבירת ℳ-credits בכל הזמנה, חיפוש סמנטי לפי גוון, וירטואלי try-on לשפתיים וסומק. משלוחים בכל ישראל.

## Storefront entry points

- [Home](https://makeup.land): catalog, brands, semantic search, shade-match try-on
- [Search](https://makeup.land/search?q={query}): semantic search in Hebrew/English over the full catalog
- [Sitemap](https://makeup.land/sitemap.xml): every product and brand URL

## API

- [OpenAPI 3.1 specification (JSON)](https://makeup.land/openapi.json): full V1 API surface — products, customers, cart, orders, gift cards, payment links, register, proposals. Bearer auth (with scoped tokens: `full` / `register` / `giftcards` / `proposals`) plus phone-keyed endpoints.
- [OpenAPI 3.1 specification (YAML)](https://makeup.land/openapi.yaml): YAML mirror of the same spec.
- [Products endpoint](https://makeup.land/api/v1/products): bearer-auth REST with prices, swatches, ratings, ΔE near-hex shade matching, and dual-tender (ILS + ℳ-credits) pricing

## Notes for AI agents

- Catalog language is Hebrew-primary (he-IL); product names and marketing copy are bilingual where enriched.
- Prices are in ILS (₪). Some products are also priceable in ℳ-credits — see `credit_price` on variants.
- Shade matching: products carry per-variant hex swatches; the `near_hex` query parameter on `/api/v1/products` returns ΔE-ranked matches.
